# AI Prompt: Environmental Monitoring Web Application

## Project Overview
Create a comprehensive web application for governments, NGOs, and urban planners to detect, track, and respond to:
- Informal settlements
- Waste management issues
- Water quality monitoring
- Forest protection
- Flood risk assessment
- Analytics and reporting

## Core Requirements

### 1. Authentication System
- **Login Page**: Functional login with email/password
- **Registration Page**: User registration with form validation
- **Session Management**: Keep users logged in after initial login
- **Database Integration**: Store user credentials securely (hashed passwords)

### 2. Database Configuration
**Recommended Solution: PostgreSQL with SQLAlchemy**

**Database Schema Example:**
```sql
-- Users table
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    first_name VARCHAR(100),
    last_name VARCHAR(100),
    organization VARCHAR(255),
    role VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Images table
CREATE TABLE uploaded_images (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    filename VARCHAR(255) NOT NULL,
    file_path VARCHAR(500) NOT NULL,
    analysis_type VARCHAR(100),
    upload_timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    analysis_results JSONB
);

-- Analysis results table
CREATE TABLE analysis_results (
    id SERIAL PRIMARY KEY,
    image_id INTEGER REFERENCES uploaded_images(id),
    detection_type VARCHAR(100),
    confidence_score FLOAT,
    coordinates JSONB,
    metadata JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Database Connection Example (Flask + SQLAlchemy):**
```python
# config.py
import os
from urllib.parse import quote_plus

class Config:
    # Replace with your actual database credentials
    DATABASE_URL = os.environ.get('DATABASE_URL') or \
        f"postgresql://username:{quote_plus('password')}@localhost:5432/environmental_monitoring"
    SQLALCHEMY_DATABASE_URI = DATABASE_URL
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    SECRET_KEY = os.environ.get('SECRET_KEY') or 'your-secret-key-here'
    UPLOAD_FOLDER = 'uploads'
    MAX_CONTENT_LENGTH = 16 * 1024 * 1024  # 16MB max file size
```

### 9. Local Development Setup
**Create these files for easy local setup:**

**run_local.py:**
```python
#!/usr/bin/env python3
import os
from app import app, db

if __name__ == '__main__':
    # Create database tables
    with app.app_context():
        db.create_all()
    
    # Run the application
    app.run(debug=True, host='0.0.0.0', port=5000)
```

**setup.sh (for Unix/Linux/Mac):**
```bash
#!/bin/bash
echo "Setting up Environmental Monitoring App..."

# Create virtual environment
python3 -m venv env
source env/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create necessary directories
mkdir -p uploads models static/css static/js static/images

echo "Setup complete! Run 'python run_local.py' to start the application."
```

# Environmental Monitoring Web Application

## Quick Start (Local Development)

1. Clone the repository
2. Run setup script:
   - On Unix/Linux/Mac: `chmod +x setup.sh && ./setup.sh`
   - On Windows: `setup.bat`
3. Configure your database in `.env` file
4. Run the application: `python run_local.py`
5. Open browser to `http://localhost:5000`

## Database Setup
1. Install PostgreSQL
2. Create database: `createdb environmental_monitoring`
3. Update DATABASE_URL in .env file
4. Run the application (tables will be created automatically)

## ML Model Integration
1. Place your trained model files in the `models/` directory
2. Update the model loading code in `ml_models.py`
3. Implement your detection functions in the respective methods

## Deployment
- GitHub: Push to repository
- Heroku: Connect GitHub repository and deploy
